# Data Scientist Companion — GitHub Pages PWA

## Publish
1. Extract this ZIP file.
2. Open your GitHub repository: `data-scientist-companion`.
3. Upload **all files and folders inside this project** to the repository root (not the enclosing folder).
4. Commit the upload to the `main` branch.
5. In the repository, open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main`, folder `/ (root)`, then Save.
8. Wait for GitHub Pages to finish deploying. Your URL will be:
   `https://YOUR-GITHUB-USERNAME.github.io/data-scientist-companion/`

## Install on Android
1. Open the published URL in Chrome.
2. Open Chrome's menu and choose **Install app** or **Add to Home screen**.
3. Launch **DS Companion** from your home screen.

## Notes
- Lessons and the app shell are cached for offline opening after the first successful online visit.
- Progress and notes remain in this browser's local storage. They are not automatically synchronised between devices. Use **Settings → Export backup** periodically.
- ChatGPT tutor links require an internet connection and a ChatGPT session.
- The reminder time is saved as a preference; this package does not schedule guaranteed background alarms or push notifications.
- To publish updates, upload the updated files to the same repository and commit them.
